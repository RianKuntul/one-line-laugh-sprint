Entry for the make.fun One-Line Laugh Sprint — one original funny line, 200 characters max, on a light, funny take on everyday life.

## Run it

```sh
node main.ts
```

Writes the one-liner to `/output/entry.txt` (override the output directory with `MAKEFUN_OUTPUT_DIR`).

## The entry

> My smart fridge texts me 'we need to talk' every time I open it at 2am, and honestly, it's right — the leftovers and I have been seeing other people.
